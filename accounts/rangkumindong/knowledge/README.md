# Rangkumin Dong — knowledge base

Single source of truth for the account. Every daily run reads these files first and updates them at the end.

| File | What it holds | Updated |
|---|---|---|
| `playbook.md` | Brand, format, script & delivery rules, visual rules, fact-check and politics rules, posting rules | When a rule changes |
| `storylines/*.md` | One file per ongoing story: fact timeline with sources, our videos, open questions, upcoming milestones, follow-up ideas | Every video on that story |
| `video-log.md` | Every video: date, topic, storyline, version, voice/A-B arm, post time, links, metrics | Every video + weekly metrics |

A copy of these is mirrored to the claude.ai "Video" project so they're readable from any device.
